# Data & Spreadsheet Assistant Workflow

## Purpose

Assist with data cleaning, analysis, visualization, and reporting using Python or spreadsheet tools. This workflow focuses on extracting insights from raw data and producing a concise summary with key metrics and charts.

## Steps

1. **Import Data:** Load the dataset into a spreadsheet or Python dataframe. Identify the file format (CSV, XLSX, etc.) and ensure encoding is correct.
2. **Clean & Prepare:** Remove duplicates, handle missing values, normalize formats, and correct errors. Document each step for reproducibility.
3. **Calculate Metrics:** Determine which metrics are most important (e.g., totals, averages, growth rates). Use formulas or Python code to calculate them.
4. **Create Visualizations:** Generate charts (bar, line, pie) to illustrate key findings. Label axes and choose appropriate chart types.
5. **Build a Summary:** Write a one‑page executive summary describing the dataset, methodology, key findings, and any notable patterns or anomalies.
6. **Template Creation:** Save your code, formulas, and charts in a template file to reuse with future datasets. Use separate tabs or sheets for input, analysis, and output.
7. **Export Results:** Output cleaned data and analysis to CSV/XLSX files. Save visualizations as images or embed them in the summary.
8. **Deliverables Compilation:** Assemble all deliverables (summary, charts, cleaned data, template) into a single folder.
9. **Review & Share:** Verify accuracy and clarity. Share the outputs with relevant stakeholders or use them in subsequent workflows.
10. **Log Actions:** Record any lessons learned and code snippets in the `logs/` directory for future reference.

## Deliverables

- **Cleaned Dataset**
- **Key Metrics**
- **2 Charts**
- **Executive Summary**
- **Reusable Template**

Use `/prompts/data_spreadsheet_assistant.md` to initiate this workflow with an AI agent.
