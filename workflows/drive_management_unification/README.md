# Drive Management Unification Workflow

## Purpose

Establish a consistent file organization system synced with Google Drive (or another cloud service) to ensure efficient storage, retrieval, and collaboration. This workflow aims to create a unified structure that all projects and agents can follow.

## Steps

1. **Define Folder Schema:** Decide on top‑level folders (e.g., Projects, Assets, SOPs, Prompts, Exports, Logs). For each, define subfolders if necessary (e.g., Projects → Brzi Arzi, Brzi Ai, Brzi Balkan).
2. **Naming Conventions:** Create rules for naming files and folders, including date formats (YYYY‑MM‑DD), descriptive slugs, version numbers, and owner tags.
3. **SOP Collection:** Gather or create standard operating procedures (SOPs) for common tasks (research, video production, music creation, etc.) and save them in the SOPs folder.
4. **Prompts & Templates:** Store prompt packs, workflow instructions, and templates in clearly labelled folders. Keep them updated as they evolve.
5. **Dashboard Document:** Develop a single document or spreadsheet linking to all active projects, deliverables, deadlines, and key resources.
6. **Initial Migration:** Move existing files into the new structure. Tag them by project and type. Check for duplicates or outdated versions.
7. **Integration & Sync:** Set up drive sync on all devices. Ensure that collaborators have access to the appropriate folders and permissions.
8. **Review & Maintain:** Schedule regular audits (e.g., monthly) to ensure folders remain organized and naming conventions are followed.
9. **Training & Onboarding:** Create a brief guide or video demonstrating the file structure and how to navigate it. Share with team members.
10. **Log Updates:** Record major structural changes or new folders in the `logs/` directory.

## Deliverables

- **Folder Schema Document**
- **Naming Convention Rules**
- **SOPs Folder** (with at least basic SOPs)
- **Dashboard Document**
- **Migration Plan**

Use `/prompts/drive_management_unification.md` to initiate this workflow with an AI agent.
