## Core Optimization Principles

### 1. Title Engineering
```yaml
Format Rules:
- Hook Type + Core Content + Urgency/Curiosity
- Maximum 60 characters
- Primary keyword in first 3 words
- Emotion trigger required

Proven Patterns:
1. ACTION + RESULT + TIMEFRAME
   Example: "Kako sam dobio 1000€ za 24 SATA"

2. DISCOVERY + IMPLICATIONS
   Example: "Pronašao sam TAJNI način da..."

3. CHALLENGE + STAKES
   Example: "Pokušao sam 100 puta dok..."

Emoji Placement Rules:
- Maximum 2-3 emojis
- First emoji after hook
- Last emoji before parentheses
- Never start with emoji
```

### 2. Thumbnail Strategy
```yaml
Technical Specifications:
- Resolution: 1280x720px
- Format: JPG/PNG < 2MB
- Text: Maximum 3 words
- Contrast ratio: Minimum 4.5:1

Design Elements:
1. Focal Point:
   - Center-weighted composition
   - High contrast background
   - Action/reaction moment

2. Text Overlay:
   - Sans-serif font
   - Stroke + Shadow required
   - 40% maximum image coverage

3. Color Psychology:
   - Red/Yellow for action
   - Blue/Green for trustworthy
   - Purple/Gold for exclusive
```

### 3. Description Optimization
```yaml
Structure:
First 2 Lines:
  - Hook question/statement
  - Value proposition

Middle Section:
  - Timestamps (if >5 min)
  - Key points/chapters
  - Related links

Bottom Section:
  - Call to action
  - Social links
  - Hashtags (max 15)

Keywords:
  - Primary: First 2 lines
  - Secondary: Natural throughout
  - LSI terms: Minimum 3
```

## Content Revival Strategy

### 1. Testing Framework
```yaml
Initial Assessment:
- Current CTR baseline
- Watch time metrics
- Engagement rate
- Traffic sources

Testing Schedule:
Day 1-3: Baseline monitoring
Day 4: First optimization
Day 7: Metrics review
Day 8-14: A/B testing
Day 15: Final implementation

Success Metrics:
- CTR increase >50%
- Watch time stable/improved
- Engagement rate >2% increase
```

### 2. Optimization Sequence
```yaml
Step 1: Thumbnail Update
- Apply new design principles
- Test for 72 hours
- Measure CTR change

Step 2: Title Optimization
- Use proven formula
- Keep keyword intent
- Monitor search traffic

Step 3: Description Refresh
- Update first 2 lines
- Add current timestamps
- Refresh calls-to-action
```

## Platform-Specific Optimizations

### 1. Shorts Optimization
```yaml
Technical Requirements:
- Duration: 15-58 seconds
- Aspect ratio: 9:16
- Resolution: 1080x1920

Content Structure:
- Hook: 0-2 seconds
- Core content: 3-45 seconds
- Call to action: Last 5 seconds

Performance Metrics:
- Target watch time: >100%
- Like ratio: >10%
- Comment rate: >1%
```

### 2. Long-Form Content
```yaml
Retention Optimization:
- Pattern interrupts every 2-3 min
- Story arc structure
- Clear value delivery

Engagement Triggers:
- Question prompts
- Community references
- Action points
```

## Analytics & Testing Framework

### 1. Key Performance Indicators
```yaml
Primary Metrics:
- CTR (Click Through Rate)
- AVD (Average View Duration)
- Engagement Rate
- Retention Graph

Secondary Metrics:
- Traffic Source Changes
- Audience Retention Points
- Re-watch Rate
- Subscription Rate
```

### 2. Testing Methodology
```yaml
A/B Testing Protocol:
1. Variable Isolation
   - One change at a time
   - 72-hour minimum test
   - Statistical significance >95%

2. Data Collection
   - Hourly first 24h
   - Daily next 6 days
   - Weekly thereafter

3. Success Criteria
   - CTR improvement >30%
   - Retention stable/improved
   - Engagement increase >20%
```

```yaml
2. Content Audit

   - Description refresh

3. Implementation
   - Staged rollout
   - Metrics tracking

4. Monitoring
   - 72h initial review

   - 30d final assessment
```

```yaml

- Title testing: Every 72h

Trigger Conditions:
```
