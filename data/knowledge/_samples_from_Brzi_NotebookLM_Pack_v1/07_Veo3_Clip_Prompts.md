# Veo 3 – 8s Klipovi (5 promptova)
**Use‑case:** kratki, viralni, loop‑friendly AI klipovi (sa zvukom/govorom).  
**Napomena:** svaku numerisanu cjelinu možeš copy/paste direktno.

## 1) USB Borba u Glitch Matrixu
Trajanje: 8s
```
Vizual: Ruka pokušava ubosti USB (2–3 neuspjela pokušaja). Pozadina sve jače glitchuje (neon mreža, "ERROR_404", "REALITY//BREAK"). Na uspjeh: "BAM!" i kratka distorzija ćilima → ploča s vodovima. Stil: cyberpunk, visok kontrast (el. plava, toksično zelena). Kamera: blago drhtava (POV), brzi zumovi.
Audio: Glitchcore x cybertrap; svaki fail “thunk” + synth glitch; uspjeh “click” + trijumfalni flourish. Šapat: “Opet, brate? Zašto?!” / “System overload! バグ!” / “Ajmo dalje! Resetuj um!”
Jezik: BHS/JP/EN.
```

## 2) Nana Glitch Filters & Džezva Rave
Trajanje: 8s
```
Vizual: Nana sjedi s telefonom; preko lica brzi anime filteri (cat ears, kawaii oči), zatim Brzi Arzi persona morph (toksično zelena kosa, neon tetovaže). Džezva u pozadini “facepalm” (oblačić: “Opet?!”). Neon pulsira u mini “balkan rave”. Stil: cel‑shaded likovi + hiperreal rekvizite.
Audio: Tradicionalna melodija → hyperpop/vocaloid trance. Glitch SFX na svaki filter. Dijalog: “Šta je ovo, dijete drago?” / “Persona‑morph engaged! Kawaii!” / “Džezva, brate, šuti! Ovo je budućnost!”
```

## 3) Ćevapi Parkour u Sarajevu 2077
Trajanje: 8s
```
Vizual: CGI ćevapi u cyber opremi rade parkour preko neon krovova Sarajeva; somun kao podloga bljeska glitch efektom; salto preko hologramskog tramvaja; završetak: “superhero landing” na tanjir.
Audio: Cybertrap x aggressive DnB; bas akcenti na slijetanja. Uzvici: “Ćevapi parkour! 2077!” / “Nema nazad!”
```

## 4) Digital Beast: Fusion Transformation
Trajanje: 8s
```
Vizual: Centralni neon vrtlog uvlači fragmente (vodovi, glifovi, lice Brzog). Transformacija u “Digital Beast” (zelena šiljata kosa, crvene oči, QR glitch). Overlay: “POWER LEVEL OVER 9000!”
Audio: Glitchcore x TrapMetal; power surge SFX; beast roar. Dijalog: “INITIATING DIGITAL REVOLUTION!” / “Fusion complete! 完了!” / “Ja sam ARZI!”
```

## 5) Adinova AI Bajka: Govoreći Oblaci
Trajanje: 8s
```
Vizual: Adin gleda u nebo; oblak postaje prijateljski emoji‑lik “Pixel”, drugi oblikuje “digitalnog zmaja”. Whimsical, blagi glow.
Audio: Ambient synthwave/lo‑fi; blagi “ding” za govor; “data flow” SFX za zmaja. Dijalog: “Tata, oblak priča!” / “Initiating story‑time…” / “Haj’ da letimo!”
```
