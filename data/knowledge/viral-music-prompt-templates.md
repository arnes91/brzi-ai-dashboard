# Viral Music Generation Templates

## Basic Structure Template
```
[Genre: {genre}]
[Style: {style}]
[Tempo: {bpm}]
[Mood: {mood}]
[Key Elements: {elements}]
[Reference Track: {reference}]
[Duration: {seconds}]

Create a {genre} track with {style} influences. The track should be {mood} and include {elements}. Take inspiration from {reference} but create something unique. Duration should be {seconds} seconds.
```

## Genre-Specific Templates

### Drill Template
```
[Genre: Drill]
[Style: Dark/Atmospheric]
[Tempo: 140-144 BPM]
[Mood: Intense/Menacing]
[Key Elements: 808 slides, heavy bass, dark melody]
[Hook Position: First 5 seconds]
[Structure: 8-bar pattern]

Create a drill beat with sliding 808s and a dark, memorable melody. Include a catchy hook within the first 5 seconds. Make the bass prominent but clean. Add atmospheric elements that create tension.

Additional Tags:
[Type Beat] [UK Drill] [Dark Trap] [Viral Sound] [TikTok Drill] [Sliding 808]
```

### Phonk Template
```
[Genre: Phonk]
[Style: Drift/Memphis]
[Tempo: 130-135 BPM]
[Mood: Energetic/Aggressive]
[Key Elements: Cowbell, heavy distortion, Memphis vocal samples]
[Hook Position: Immediate]
[Structure: 4-bar intro + 4-bar drop]

Generate a high-energy phonk track with prominent cowbell and distorted bass. Include aggressive synth elements and a strong, immediate hook. Focus on creating a powerful drop section.

Additional Tags:
[Phonk] [Drift Phonk] [TikTok Phonk] [Gym Motivation] [Viral Phonk] [Car Scene]
```

### Hyperpop Template
```
[Genre: Hyperpop]
[Style: Glitch/Pop]
[Tempo: 145-160 BPM]
[Mood: Energetic/Chaotic]
[Key Elements: Pitched vocals, heavy autotune, glitch effects]
[Hook Position: Within 3 seconds]
[Structure: Verse-chorus mashup]

Create a high-energy hyperpop track with heavily processed vocals and glitch effects. Include sudden pitch changes and energetic synthesizers. Make it catchy and chaotic.

Additional Tags:
[Hyperpop] [Glitchcore] [TikTok Sound] [Electronic] [Viral Music] [Gen Z Pop]
```

## Length Variations

### 5-Second Hook Template
```
[Duration: 5 seconds]
[Focus: Hook only]
[Structure: Instant impact]
[Key Elements: One memorable phrase, strong beat drop]

Create a 5-second hook that captures attention immediately. Focus on one strong musical phrase or beat drop that loops perfectly.
```

### 15-Second Template
```
[Duration: 15 seconds]
[Structure: 3-second intro + 12-second main]
[Hook Position: 0-3 seconds]
[Elements: Build-up and payoff]

Generate a 15-second track with an immediate hook followed by a satisfying progression. Ensure it loops seamlessly for TikTok/Shorts.
```

### 30-Second Full Template
```
[Duration: 30 seconds]
[Structure: Intro-Hook-Bridge-Outro]
[Key Positions: Hook at 0-5s, Bridge at 15s]
[Loop Points: 15s mark for shorter edits]

Create a complete 30-second track that can be edited down to smaller segments. Include clear transition points at 15 seconds for easy editing.
```

## Post-Processing Instructions

### Effects Chain
```
- Add slight saturation to enhance presence
- Apply sidechain compression for pumping effect
- Include subtle reverb (30% wet)
- Master for mobile device playback
- Ensure -6dB headroom
- Apply loudness normalization (target: -14 LUFS)
```

### Export Variations
```
Generate these versions:
1. Original tempo
2. Sped up (+10-15%)
3. Slowed + Reverb version
4. Nightcore version (+20-30%)
5. Bass boosted version
```
