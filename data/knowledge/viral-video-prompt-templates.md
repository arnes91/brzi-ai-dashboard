## Short Clip Templates

### 5-Second Impact Clips
```
[Duration: 5 seconds]
[Format: Vertical 9:16]
[Resolution: 1080x1920]
[Frame Rate: 60fps]

Category 1: Transition Clips
- "A smooth camera movement through {object/scene}, transitioning from {starting point} to {ending point} with a cinematic flow"
- "Quick zoom into {object}, revealing {unexpected element} with a dramatic push effect"
- "Seamless morph from {object A} to {object B} using liquid transition effect"

Category 2: Reveal Clips
- "Close-up of {object} that dramatically pulls back to reveal {larger scene}"
- "Slow motion capture of {action} with particle effects enhancing the movement"
- "POV shot approaching {object} with a satisfying reveal at the end"

Style Modifiers:
[Cinematic] [Hyperreal] [Dreamy] [High Contrast] [Neon-lit]
```

### 10-Second Story Clips
```
[Duration: 10 seconds]
[Format: Vertical 9:16]
[Resolution: 1080x1920]
[Frame Rate: 60fps]

Structure Templates:
1. Before/After Format
```
First 5s: "{initial state/scene} with {specific lighting/mood}"
Last 5s: "Transformed into {final state/scene} maintaining {consistent element}"
```

2. Build-up Format
```
0-3s: "Start with {simple element}"
3-7s: "Gradually add {progressive changes}"
7-10s: "Culminate in {impressive finale}"
```

3. Loop Format
```
Create a seamless 10-second loop where {action/scene} smoothly transitions back to the beginning
Include {repeating element} that creates visual continuity
```

Movement Instructions:
- Start: [Slow/Steady]
- Middle: [Build Momentum]
- End: [Impact/Resolution]
```

## Transition Templates

### Smooth Transitions
```
1. Zoom Transition
"Zoom into {focal point} until it fills the frame, then seamlessly transition to {new scene} starting zoomed in and pulling back"

2. Rotation Transition
"Rotate around {central object} while it transforms into {new object}, maintaining smooth camera movement"

3. Color Flow Transition
"Use {dominant color} to flow across the screen, morphing the scene from {scene A} to {scene B}"
```

### Match Cut Templates
```
1. Shape Match
"Transition from {round object A} to {round object B} using matching circular forms"

2. Movement Match
"Match {movement in scene A} with similar movement in {scene B} for seamless flow"

3. Color Match
"Use {color} as dominant tone to blend {scene A} into {scene B}"
```

## Editing Instructions

### Visual Effects
```
Apply these effects for optimal mobile viewing:
- Increase contrast by 10-15%
- Boost saturation selectively
- Add subtle vignette
- Implement motion blur on fast movements
- Use speed ramping at transition points
```

### Export Settings
```
Generate these versions:
1. Full quality vertical (1080x1920)
2. Compressed version for TikTok
3. Square crop for Instagram (1080x1080)
4. Horizontal crop for YouTube (1920x1080)
5. Low-res preview version
```

### Loop Optimization
```
For all clips:
- Ensure first and last frame match for perfect loops
- Add 1-frame crossfade at loop point
- Test loop minimum 3 times
- Check motion flow at loop point
- Verify audio sync points
```
