## 💡 Production Tips

### For Best Results:
1. **Camera Movement:**
   - Specify smooth movements
   - Add "cinematic" to get film-like quality
   - Use terms like "tracking shot," "dolly," "crane shot"

2. **Lighting:**
   - "Volumetric lighting" for atmospheric scenes
   - "Rim lighting" for tech products
   - "Dynamic lighting" for energy

3. **Quality Markers:**
   - "Photorealistic"
   - "8K quality"
   - "Hyperrealistic detail"

### Mixing Formats:
1. **For 5-second clips (720p):**
   - Focus on single, impactful movements
   - Clear, simple transitions
   - Strong visual hooks

2. **For 10-second clips (480p):**
   - Include more narrative elements
   - Add progressive transformations
   - Layer multiple effects

## 📝 Prompt Structure Template

```markdown
[Main Subject] + [Action/Movement] + [Environment] + [Lighting] + [Camera Movement] + [Style/Mood]

Example:
"A gaming setup (subject) transforming (action) in a minimalist room (environment) with RGB accent lighting (lighting), smooth dolly shot (camera), cyberpunk style (mood)"
```

Remember: Experiment with combinations and don't be afraid to generate multiple versions of the same prompt. Sometimes the "mistakes" create the most interesting content! 🚀
