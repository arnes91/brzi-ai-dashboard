# Prompt Pack – Drive Management Unification

Use this prompt to create a unified, labeled workspace structure synced to cloud storage, ensuring easy navigation and collaboration.

## Goal

Design a consistent folder schema, naming conventions, SOP collection, and dashboard document to organize all files across projects.

## Deliverables

- **Folder Schema:** A hierarchical structure for organizing projects, assets, SOPs, prompts, templates, exports, and logs.
- **Naming Convention Rules:** Standards for dates, slugs, versions, and owner tags.
- **SOP Collection:** List of standard operating procedures saved in the appropriate folder.
- **Dashboard Document:** Central hub linking active projects, goals, and resources.
- **Migration Plan:** Steps to move existing files into the new structure and sync across devices.

## Instructions

1. Define top‑level and subfolder categories that reflect your projects and work areas.
2. Create naming rules that enforce consistency across all file names.
3. Gather existing SOPs or draft new ones; store them in an `SOPs` folder.
4. Build a dashboard document or spreadsheet that summarizes current projects, deadlines, and key links.
5. Plan and execute the migration of files into the new structure. Check for duplicates or outdated versions.
6. Configure drive sync on all devices and set appropriate access permissions.
7. Schedule periodic audits to maintain organization.
8. Document any structural changes or new folders in the logs.
