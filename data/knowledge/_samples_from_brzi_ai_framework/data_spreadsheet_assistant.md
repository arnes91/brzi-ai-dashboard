# Prompt Pack – Data & Spreadsheet Assistant

Use this prompt to clean, analyze, and visualize datasets using Python or spreadsheet tools.

## Goal

Transform raw data into actionable insights. Produce a cleaned dataset, key metrics, charts, and an executive summary using reproducible methods.

## Deliverables

- **Cleaned Dataset:** A version of the data free from duplicates, errors, and missing values.
- **Metrics:** At least five calculated metrics relevant to the dataset.
- **Charts:** Two visualizations illustrating important trends or comparisons.
- **Summary:** A one‑page narrative explaining context, methodology, findings, and notable patterns.
- **Reusable Template:** Code or spreadsheet template for repeating the analysis on future datasets.

## Instructions

1. Load the dataset and inspect its structure (columns, types, missing values).
2. Clean the data by handling duplicates, nulls, and format inconsistencies.
3. Determine which metrics are meaningful and calculate them.
4. Create appropriate charts with titles and labeled axes.
5. Write a summary that contextualizes the data and highlights key findings.
6. Save your code, formulas, and outputs in a template file.
7. Export the cleaned data and summary to share with stakeholders.
8. Record any issues, anomalies, or follow‑up questions in the logs.

Attach the Base Context when issuing this prompt.
