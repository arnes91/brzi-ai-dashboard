# Workflows Overview

Workflows translate prompt packs into actionable sequences. Each workflow file in the `workflows/` directory contains step‑by‑step instructions, deliverables, and templates to complete a specific type of task. Use these workflows to stay organized, delegate effectively, and maintain quality.

## Workflow List

- **Deep Research Sprint:** Conduct focused research to create an executive brief, opportunity map, monetization strategies, source citations, and next actions.
- **Content Pipeline – YouTube:** Build a video from concept to upload, including scripting, SEO, editing, and promotional tasks.
- **Music Agent – Track to Release:** Produce and release a music track using AI tools, with prompts, selection processes, metadata, and promotional kits.
- **Rapid SaaS/Tool Experiment:** Launch a simple SaaS concept quickly, covering ideation, UI scaffolding, database setup, analytics, and go/no‑go criteria.
- **Monetization & Outreach:** Identify revenue opportunities, craft outreach messages, set up CRM tracking, and schedule follow‑ups.
- **Automation & Agents:** Identify repeatable tasks and design automations using tools like Zapier, Make, or native integrations. Include safety rails and pilot tests.
- **Drive Management Unification:** Standardize file organization, naming, and SOPs across projects, and provide a dashboard for quick access to resources.
- **Data & Spreadsheet Assistant:** Process datasets with code or spreadsheets, generate metrics, charts, and a one‑page summary, and create a reusable template.

Detailed instructions for each workflow can be found in the corresponding subdirectory in `workflows/`.
