# Prompt Pack – Automation & Agents

Use this prompt to identify and implement automations that reduce manual work and enable seamless coordination across tools.

## Goal

Map recurring tasks and propose automations using platforms like Zapier, Make, or native integrations. Design safe, reliable flows and implement a pilot automation.

## Deliverables

- **Task Inventory:** List of repeatable tasks, frequency, and effort.
- **Trigger‑Action Maps:** Definitions of triggers and resulting actions.
- **Automation Flowchart:** High‑level diagram or description of each automation.
- **Pilot Automation:** A single tested automation with documented steps.
- **Safety & Error Handling Notes:** Rate limits, retries, privacy considerations.
- **Deployment Plan:** Steps to roll out successful automations across projects.

## Instructions

1. Brainstorm all repetitive tasks across projects and document them.
2. For each task, determine the event that triggers it and the desired actions.
3. Select the appropriate automation platform based on cost and capabilities.
4. Draft the flow for each automation, including filters and conditions.
5. Define safety rails and privacy requirements.
6. Build one pilot automation and test it with sample data.
7. Document the setup in detail, including settings and error handling.
8. If successful, schedule deployment and maintain logs of performance.
9. Present next steps and potential automations to explore.
