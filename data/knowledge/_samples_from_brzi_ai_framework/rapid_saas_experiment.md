# Prompt Pack – Rapid SaaS/Tool Experiment

Use this prompt to test a SaaS or tool idea quickly and cheaply, producing a working prototype within three days.

## Goal

Validate a niche SaaS concept using free or low‑cost tools. Deliver a one‑pager, UI scaffold, database setup, and a launch checklist.

## Deliverables

- **One‑Pager:** Problem, JTBD, user promise, pricing sketch.
- **UI Scaffold:** Basic code and design for the main interface.
- **Database Notes:** Schema, authentication configuration, and security rules.
- **Feedback Mechanism:** Survey or form to capture user responses.
- **Analytics Integration:** Basic metrics and tracking.
- **Launch Checklist & Decision Criteria:** Go/no‑go thresholds and next steps.

## Instructions

1. Define the problem clearly and specify the target audience.
2. Use an AI code generator (e.g., Vercel v0.dev) to produce a minimal UI. Refine manually if necessary.
3. Choose a backend (e.g., Firebase) and set up authentication and a simple schema.
4. Integrate a feedback form or survey into the UI.
5. Add lightweight analytics to monitor user engagement.
6. Deploy the app on a free platform; share the link with potential users.
7. Collect and analyze feedback; decide whether to iterate, expand, or abandon.
8. Document the entire process for future reference.
