# Prompt Pack – Music Agent (Track to Release)

Use this prompt to generate and release an AI‑assisted music track with minimal manual effort.

## Goal

Create, select, and publish a track that fits the Brzi Arzi style (glitch techno, cyberpunk rap, Balkan fusion) with multilingual lyrics. Deliver a complete release pack and promotional plan.

## Deliverables

- **Style Prompt Pack:** Detailed description of desired genre, mood, tempo, languages, instrumentation, and thematic elements.
- **Hook Variants:** Multiple 30‑ and 60‑second hooks with notes on selection criteria.
- **Selection Analysis:** Explanation of why the chosen variant was selected.
- **Full Track:** AI‑generated track based on the selected hook.
- **Release Pack:** Title, cover art concept, metadata, distribution checklist.
- **Promo Kit:** Three short scripts for social posts, five hashtags, seven‑day posting schedule.

## Instructions

1. Write a detailed style prompt using the template provided.
2. Generate multiple hook variants with Producer or Suno; document the parameters used.
3. Evaluate and select the best hook; explain your choice.
4. Use the chosen hook to produce a full track; adjust as needed.
5. Prepare the release pack with all required metadata and distribution steps.
6. Develop a promotional plan with scripts and schedule.
7. Provide next actions for distribution and promotion.

This prompt assumes the Base Context has been provided. Update the style and theme details as necessary before issuing the prompt.
