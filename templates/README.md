# Templates Overview

This folder contains ready‑to‑use templates to streamline your workflows. Templates provide standardized structures for planning, drafting, and documenting tasks. Copy and customize them as needed.

Available templates:

- **youtube_video_plan_template.md** – Outline for planning YouTube videos.
- **music_prompt_template.md** – Scaffold for crafting style prompts for music generation.
- **music_release_template.md** – Structure for the release pack when publishing a track.
- **saas_onepager_template.md** – One‑pager for articulating a SaaS idea.
- **outreach_script_template.md** – Base script for outreach messages.
- **automation_mapping_template.md** – Form for documenting automation triggers and actions.
- **drive_structure_template.md** – Template describing folder schema and naming conventions.
- **data_assistant_template.md** – Checklist for data cleaning and analysis.
- **cross_context_log_template.md** – Log entry template for cross‑agent context sharing.
