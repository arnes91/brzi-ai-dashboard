## Naming Convention Rules

- **Date Prefix:** Use `YYYY‑MM‑DD` at the beginning of filenames (e.g., `2025‑09‑18_script_draft.md`).
- **Slug:** Use descriptive slugs separated by underscores (e.g., `hook_variants`).
- **Version:** Append `v#` when multiple versions exist (e.g., `_v1`, `_v2`).
- **Owner:** Optionally include initials to indicate the creator (e.g., `_aa` for Arnes).

## Tips

1. **Consistency:** Apply the same schema across all devices and collaborators.
2. **Labels & Tags:** Use drive labels or tags to categorize files (e.g., “Final,” “Draft,” “Promoted”).
3. **Access Control:** Set appropriate permissions for each folder based on team roles.
4. **Periodic Review:** Audit the structure monthly to remove duplicates and archive old files.
