# Automation Mapping Template

Document each automation in a standardized format to ensure clarity and reproducibility.

## Automation Name

A concise title describing the automation (e.g., “YouTube Upload → Social Posts”).

## Objective

Explain why this automation exists and what manual process it replaces.

## Trigger

Describe the event that triggers the automation (e.g., new file added to folder, form submission).

## Actions

List each action taken after the trigger fires. For each action, specify the tool/service used (e.g., Zapier step, API call).

3. Action 3 – Tool/Service – Description

## Conditions & Filters

Detail any conditions that must be met for the automation to proceed (e.g., file type, tag presence).

## Safety Measures

- **Error Handling:** (e.g., retry logic, notifications)
- **Privacy Considerations:** (e.g., exclude sensitive data)

## Test Data

Describe the test data or scenario used to validate the automation.
