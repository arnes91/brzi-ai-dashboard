# Documentation Index

This `docs` folder contains the core documentation for the Brzi AI Framework. Each file explains a specific aspect of the ecosystem and provides guidelines for using and updating this knowledge base.

- **GUIDEBOOK.md** – The foundational guidebook describing Arnes’ identity, mission, philosophy, current setup, projects, services, and social context.
- **ENVIRONMENT_SETUP.md** – Instructions and notes for configuring and maintaining the hardware, software, and AI tool environment.
- **AGENTS.md** – Descriptions and usage guidelines for the various AI agents, assistants, and agentic tools used in the Brzi ecosystem.
- **TOOLS.md** – A catalog of models, connectors, platforms, and services, including capabilities and recommended use cases.
- **PROJECTS.md** – Overviews of the main projects (Brzi Arzi music, Brzi Ai hub, Brzi Balkan) and how they interconnect.
- **PROMPT_PACKS_OVERVIEW.md** – Summary of the modular prompt packs and when to apply them.
- **WORKFLOWS_OVERVIEW.md** – Index of available workflows and how to follow them.
- **CROSS_CONTEXT.md** – Guidelines for maintaining shared context and synchronizing information across agents and platforms.

Use these documents as reference when onboarding new collaborators or updating the system.
