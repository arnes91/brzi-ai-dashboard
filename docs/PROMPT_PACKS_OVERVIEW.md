# Prompt Packs Overview

Prompt packs are modular collections of instructions designed to jump‑start tasks for AI agents. Each pack focuses on a specific workflow and includes a concise description of the desired output, deliverables, and constraints. Use them as templates to ensure consistent results and to save time.

## Available Prompt Packs

1. **Base Context:** The foundation of all conversations; describes the mission, identity, operating principles, and decision heuristics. Always include this at the start of a new chat.
2. **Custom Instructions:** Defines your preferred tone, format, and interaction style. Use when setting up personalization settings or starting a new session.
3. **Deep Research Sprint:** Guides agents to deliver an executive brief, opportunity map, monetization plays, sources, and next actions.
4. **Content Pipeline – YouTube:** Outlines a one‑video production flow from idea to upload, including scripts, SEO, and post‑production checklists.
5. **Music Agent – Track to Release:** Provides a framework for creating and releasing a music track with minimal manual effort, including style prompts and release metadata.
6. **Rapid SaaS/Tool Experiment:** Helps validate a simple SaaS idea on a free tier within one to three days, covering problem definition, UI scaffolding, and launch criteria.
7. **Monetization & Outreach:** Generates revenue opportunities, outreach scripts, CRM schema, and daily tasks.
8. **Automation & Agents:** Maps repeatable tasks to potential automations and suggests flows using Zapier, Make, or other services.
9. **Drive Management Unification:** Defines a consistent folder schema, naming conventions, SOPs, and dashboard for knowledge management.
10. **Data & Spreadsheet Assistant:** Provides guidance for cleaning datasets, calculating metrics, creating charts, and producing summaries.

Refer to the files in the `prompts/` directory for detailed instructions for each pack.
